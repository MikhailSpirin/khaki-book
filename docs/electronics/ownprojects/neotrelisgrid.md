Recently i successfully built a Norns (shield version) from pushermanpcb kit - https://pushermanproductions.com/product/partial-kit-norns-shield-pi4-v210330-white-screen-no-raspberry-pi-memory-card-copy/

Great tool and i like lots of amazing generative apps on it, but i became clear that i need some c ontrol panel. I expected that such additional tool will open lots of possibilities. Also, most complicated apps mentioned the need of controller to run.
Most obvious way was grid. Though, used controller costs a lot (from 600 USD on used market). So I went to DIY scene to check if there are any options there.

And I found not that old product! https://llllllll.co/t/diy-monome-compatible-grid-w-adafruit-neotrellis/28106
Seems to be fairly simple, so i started ordering.
